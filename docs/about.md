# About

Memory Card is a video game collection manager that runs as a Home Assistant
app. It keeps one shared collection for everyone at home, and each person's play
apart. It is free and open source, made by [Claudio Sanches](https://github.com/claudiosanches).

## Source code

- [Memory Card](https://github.com/claudiosanches/ha-memory-card): the app.
- [Memory Card integration](https://github.com/claudiosanches/ha-memory-card-integration):
  the custom integration that brings its sensors and a **Roll a pick** button
  into Home Assistant.

Both are released under the Apache License 2.0.

## Help and feedback

Questions, ideas and bug reports go to
[GitHub issues](https://github.com/claudiosanches/ha-memory-card/issues).
For a bug, say which version of Memory Card you run and add the lines around
the problem from the app's **Log** tab.
