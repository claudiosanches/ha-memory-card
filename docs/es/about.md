# Acerca de

Memory Card es un gestor de colección de videojuegos que funciona como una
aplicación de Home Assistant. Mantiene una colección para toda la casa y el
registro de juego de cada persona por separado. Es gratuito y de código
abierto, creado por [Claudio Sanches](https://github.com/claudiosanches).

## Código fuente

- [Memory Card](https://github.com/claudiosanches/ha-memory-card): la aplicación.
- [Integración Memory Card](https://github.com/claudiosanches/ha-memory-card-integration):
  la integración personalizada que lleva sus sensores y un botón **Roll a pick**
  a Home Assistant.

Ambos se publican bajo la licencia Apache 2.0.

## Ayuda y comentarios

Las preguntas, ideas y avisos de errores van a
[GitHub issues](https://github.com/claudiosanches/ha-memory-card/issues).
Para informar de un error, indica qué versión de Memory Card usas y añade las
líneas cercanas al problema desde la pestaña **Registro** de la aplicación.

## Créditos

- Iconos de interfaz de [Tabler Icons](https://tabler.io/icons) (MIT).
- Metadatos y portadas de juegos de [IGDB](https://www.igdb.com), cuando las
  credenciales de IGDB están configuradas.
- Nombres de producto para códigos de barras leídos desde
  [UPCitemdb](https://www.upcitemdb.com).
