# Hardware

**Hardware** en la barra lateral lista las consolas, mandos, accesorios y
juguetes que tienes o quieres. Todos pueden explorarlo; los gestores lo
añaden y modifican.

![Hardware, con consolas, mandos y amiibo](https://ha-memory-card.pages.dev/images/hardware.webp)

Busca por nombre, modelo, plataforma o notas, usa el desplegable para alternar
entre lo que tienes, la lista de deseos y todo el hardware, y elige una pestaña
de tipo para acotar la lista. Seleccionar el número de copias en una consola,
portátil o PC abre esos juegos en la [Biblioteca](library.md).

## Tipos

- **Consola**, **Portátil** y **PC** contienen juegos: cada copia puede indicar
  en cuál está. **Ejecuta** lista las plataformas cuyos juegos ejecuta el
  dispositivo, así que una PS5 ejecuta PS5 y PS4.
- **Mando**, **Accesorio** y **Juguete o figura**, como los amiibo, no contienen
  juegos. **Para** indica la plataforma con la que van.

Un dispositivo con copias asignadas no puede convertirse en mando, accesorio ni
juguete.

Las cuentas de tienda, como una Cuenta Nintendo o Steam, no son hardware. Están
en **Gestionar > Cuentas**. Consulta [Gestionar](manage.md#accounts).

## Añadir hardware

**Añadir hardware** pide:

- **Lo tengo** o **En mi lista de deseos**;
- un nombre que lo distinga del resto, como «Switch del salón». Los nombres son
  únicos, así que dos mandos iguales necesitan nombres distintos, como
  «Mando Pro (azul)»;
- el tipo y el modelo, como «Switch OLED»;
- las plataformas que ejecuta o la plataforma para la que es;
- región, conservación, dónde y cuándo se compró, cuánto costó y por cuánto se
  vendería hoy, número de serie y código de barras, igual que en las copias;
- notas.

Las consolas inactivas no aparecen al elegir dónde está una copia. Eliminar un
dispositivo conserva sus copias sin dispositivo.

## Fotos

El botón de cámara de una tarjeta añade fotos, como la caja o la etiqueta con el
número de serie, hasta 20 por artículo. Selecciona una para verla a tamaño
completo. Memory Card elimina la ubicación y otros metadatos que un teléfono
guarda en la foto, igual que en las copias.

## Lista de deseos y estadísticas

Cambia a **Lista de deseos** arriba en la página Hardware para ver el hardware
que quieres. **Ya lo tengo** abre el formulario como propio para rellenar dónde
lo compraste y cuánto pagaste.

[Estadísticas](stats.md) tiene un grupo **Hardware** con cuántos artículos
tienes por tipo, cuánto costaron y cuánto valen hoy, aparte de los juegos.

## CSV

**Importar / exportar** tiene una pestaña **Hardware** para un archivo CSV con
tu hardware. Consulta [Importar / exportar](import-export.md#hardware).
