# Sobre

O Memory Card é um gerenciador de coleção de jogos que roda como aplicativo no
Home Assistant. Ele mantém uma coleção compartilhada por quem mora na casa e
separa as partidas de cada pessoa. É gratuito e de código aberto, criado por
[Claudio Sanches](https://github.com/claudiosanches).

## Código-fonte

- [Memory Card](https://github.com/claudiosanches/ha-memory-card): o aplicativo.
- [Integração Memory Card](https://github.com/claudiosanches/ha-memory-card-integration):
  a integração personalizada que traz os sensores e o botão **Sortear um jogo**
  para o Home Assistant.

Ambos são distribuídos sob a licença Apache 2.0.

## Ajuda e sugestões

Dúvidas, ideias e relatos de erros vão para as
[issues no GitHub](https://github.com/claudiosanches/ha-memory-card/issues).
Para relatar um erro, informe qual versão do Memory Card você usa e inclua as
linhas próximas ao problema da aba **Log** do aplicativo.

## Créditos

- Ícones da interface do [Tabler Icons](https://tabler.io/icons) (MIT).
- Metadados e capas de jogos do [IGDB](https://www.igdb.com), quando as
  credenciais do IGDB estão configuradas.
- Nomes de produtos para códigos de barras lidos do
  [UPCitemdb](https://www.upcitemdb.com).

## Marcas registradas

Títulos de jogos, capas e outras marcas exibidos neste site e no aplicativo
pertencem aos seus respectivos proprietários. O Memory Card não é afiliado nem
endossado por eles.
